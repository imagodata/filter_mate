🚀 360 577 bâtiments. 12 couches. UN clic. Le tout dans QGIS.

C'est FilterMate 5.1, et ça se regarde en 55 secondes 👇 (vidéo en anglais, avec le son 🔊)

Fini d'exporter, de découper et de réimporter. Posez votre question spatiale une seule fois :

🗺️ Vecteur, raster, nuage de points : chaque couche peut être source ou cible
⚡ Le filtre s'écrit dans le SQL de chaque source (PostGIS, GeoPackage, SpatiaLite, fichiers) : rien n'est copié
🔗 Enchaînez : ET, OU, SAUF, sur plusieurs cibles à la fois
🏢 LiDAR : tous les bâtiments de plus de 7 m, lus dans le nuage de points
↩️ Annuler, Rétablir, et Comparer : une ligne glisse sur la carte et montre l'avant et l'après
📦 Exportez seulement la réponse, dans un GeoPackage qui garde votre projet
🤖 Automatisez le tout : Processing, API Python et REST, MCP

Et deux toutes nouvelles sections (expérimentales, et déjà bluffantes) :

🎯 SAM : un clic sur l'orthophoto détoure l'objet. Sur votre processeur. Sans carte graphique, sans compte.
💬 AGENT : demandez en une phrase, vérifiez chaque étape, annulez d'un clic. Votre propre clé d'API, ou un modèle local Ollama : dans la vidéo, il tourne sur mon portable et rien n'en sort.

Aucune maquette : chaque seconde est le vrai plugin dans QGIS 4.2, sur les données ouvertes de l'IGN 🇫🇷

✅ Gratuit ✅ Open source ✅ QGIS 3.22 à 4.x
