about=FilterMate filters several layers at once, from one panel. Select something on a layer and the other layers of the project keep only what relates to it: buildings near main roads, parcels on steep slopes, LiDAR points under rooftops.

    🧭 EXPLORING: select on any layer. Features or an expression on a vector layer, a range of values on a raster (DEM, orthophoto), classes, heights or intensity on a point cloud (LAS, LAZ, COPC).
    🔍 FILTERING: keep in the other layers what intersects, touches or lies within a distance of the selection, and combine it with their current filters. A vector layer is filtered by its own definition query: nothing is copied, styles stay.
    📦 EXPORTING: save the filtered layers (GeoPackage, Shapefile, GeoTIFF, LAZ...).
    ↩️ Undo and redo every filter, keep favorites, compare the map before and after.

    🤖 AGENT (experimental, optional): type or dictate a request, for example "buildings above 1200 m in the selected commune". It filters, selects, styles, brings data in (OpenStreetMap, elevation, population, WMS), draws charts, makes print layouts and atlases, and exports, step by step. Choose Respond, Propose or Act to control changes, guide a running request with Push or queue the next one, and choose reasoning effort when your model supports it. New conversation archives the exchanges; History reopens them without replaying past actions. Use your own key for Claude, Mistral or OpenAI, or a local Ollama model for the chat. No FilterMate account, no telemetry. What is sent and when: https://github.com/imagodata/filter_mate/blob/main/docs/AI_AND_DATA.md

    💾 Agent data stay in project memory where possible. Save project and layers asks where to keep the project and its in-memory datasets; file-only providers use that chosen folder. Choose a default export folder and save pending layer edits only after a separate confirmation. Save suggestions can be hidden until QGIS restarts. Click layer links to reveal them in the Layers panel, or output actions to open files and folders.
    🌐 Dataset discovery recommends suitable sources, including disabled ones. Optional Web search finds unverified candidate portals and services; a prefilled Sources form lets you review, test and add them. Sources are not enabled and layers are not loaded by a recommendation alone.
    🗺️ Ask whether the project CRS suits the data and analysis, navigate with cancellable smooth zoom, and open QGIS tables, layer properties or existing plugin panels from the chat.
    🧩 Processing: discover compatible algorithms from installed active providers and run registered models. Agent Processing runs that require files need QGIS 3.32 or later.
    🎙️ Dictation: choose a microphone and a local compatible transcription service, OpenAI or Mistral in Microphone settings, independently of the chat model. Test the input level and a ten-second transcription before saving the settings. Dictation stays in RAM for up to two minutes and the recognized text goes into the draft for review before Send. Cloud transcription sends audio only to the chosen service; its key stays in the QGIS authentication database. Qt Multimedia is required for microphone input.

    Works with PostGIS, GeoPackage, Spatialite, files, WFS, WMS and tile basemaps. The dock can save a web-layer copy beside the project for offline use; agent copies follow the memory and chosen-folder workflow above. QGIS 3.22 to 4.x, Qt5 and Qt6, 34 languages, light and dark themes. Processing algorithms and a Python API for automation.
    Optional, installed only if you agree: psycopg2 for PostgreSQL, PDAL for heights above the ground, onnxruntime to draw objects on images with SAM.

changelog=5.1.3: dataset discovery, saved conversations, microphone tests and QGIS workflows
    - Recommend suitable data sources even when they are disabled. Optional Web search finds unverified candidates; review, test and add a proposed source in a prefilled form without automatic activation or layer loading.
    - New conversation archives the exchanges. History reopens conversations in their project or displays those from other projects, without replaying actions. Model context resumes only when its destination and sharing settings are compatible.
    - Guide the running request with Push or keep the next message in Queue, with Send now for queued requests and Esc to stop.
    - Agent downloads and outputs stay in project memory where possible. Save project and layers asks for their destination, suggests a relevant folder and saves datasets beside the project; file-only providers use the chosen data folder. Save suggestions can be muted until QGIS restarts.
    - The first agent export asks for a default folder and remembers it. Saving pending layer edits to their source requires a separate confirmation. Export and project-save destinations inside QGIS profiles are refused.
    - Clickable layer names reveal their layer in the tree. Exports provide file and folder actions; web links open on click.
    - Compatible installed Processing providers and registered models can run through the agent; file-based agent runs require QGIS 3.32 or later. The unstable model designer integration is disabled and removed from the agent menu.
    - Optional dictation through a local compatible service, OpenAI or Mistral, independent of the chat provider. Test the microphone level and a short transcription with unsaved settings. Two-minute dictation stays in RAM and fills an editable draft for review before Send.
    - Assess the suitability of the current project CRS and recommend whether to keep or change it. Smooth zoom stops on manual navigation and preserves a single Previous view step; point and mixed extents stay visible.
    - Discover available QGIS actions and existing plugin panels; open attribute tables, layer properties and supported map tools from the chat.
    - Cancellable selection and highlight reads use background snapshots. Late results do not replace manual selections. Actions requiring undo are refused when their state cannot be captured; oversized managed Processing results are rejected before layer creation.
    - Agent menus stay open while toggling sources, the plugin MCP server and live recipes, so several choices can be changed in one visit with the mouse or keyboard.
    - A persistent network icon shows task and interaction states; local busy cursors preserve QGIS map tools and restore correctly after cancellation.
    - Loaded skills are reused and recent instructions remain available when tool results are trimmed. Shared notes detect updates from other QGIS sessions.
    - Recent agent actions are translated in all 34 languages, with French microphone labels and errors. VRT persistence rejects DTDs while preserving escaped and relative raster paths.
    - Official regional basemaps and five Esri alternatives join source discovery. CARTO requires a personal API key; connection checks respect QGIS proxy settings and reject empty or redirected responses.
    - Expression evaluation keeps the same project and layer variables, measurement units, CRS and ellipsoid in the foreground and in background tasks.
    - GeoPackage copies keep their SQLite filters when a project is saved and reopened, without sending them to WFS. A cancelled copy-again operation restores the previous copy and its filter.
    - Agent workflows: Respond, Propose or Act, individual action confirmations, clearer tool families, GUI previews, and saving the current filter as a favorite from the chat or the API.
    - Incompatible conversation recaps are not sent to another provider, account or sharing setting. Choosing a layer with @ inserts the selected layer correctly.
    - Optional reasoning effort for supported models, remembered per model and server; Automatic keeps the provider default. Compact navigation icons follow the theme and long model names stay readable in tooltips.
    - EXPLORING keeps its source-layer chooser when FILTERING is hidden. Long conversation saves are faster, standalone REST imports work without QGIS, and the compiled French catalog includes the new interface labels.
    - Charts rendered in Python, vector infographics, and fixes to favorites, zooming, exports and project persistence.
