about=🧭 FilterMate explores, filters and exports vector, raster and LiDAR point cloud layers from one panel.

    Pick a layer, select what matters on it, and FilterMate filters the other layers of the project by their relation to that selection: buildings near main roads, parcels on steep slopes, LiDAR points beneath rooftops, a DTM clipped around a church. Filters stay on the existing project layers, keep their styles, can be undone, saved as favorites, exported and replayed from Processing.

    🧭 EXPLORING selects on the current layer, whatever its kind:
    - 🗺️ vector: one feature, several, or an expression;
    - 🏔️ raster: band, pixel value picked on the map, value range on a live histogram, classes, raster calculator expression;
    - ☁️ point cloud (LAS, LAZ, COPC, EPT, VPC): ASPRS / LiDAR HD classes, Z, intensity and return ranges, attribute conditions, height above a DTM.

    🔍 FILTERING relates that selection to layers of any kind (9 source / target combinations) with geometric predicates, a buffer, AND / OR with existing filters and a minimum coverage for polygons. Filtered rasters and point clouds keep their id, style and place in the layer tree, and the project is always saved with the original sources.

    📦 EXPORTING writes the filtered layers: vector formats, GeoPackage with an embedded QGIS project, GeoTIFF / COG, LAZ / LAS / COPC.

    ✨ Also: PostgreSQL / PostGIS, Spatialite, GeoPackage and OGR backends with spatial indexes; undo / redo; favorites shared through git repositories; Processing algorithms and models, qgis_process, Python and REST APIs; light and dark themes; 34 languages. QGIS 3.22 to 4.x, Qt5 and Qt6.

    🔧 Optional: psycopg2 for PostgreSQL, PDAL 2.4+ for the height above a DTM and COPC writing.

    📖 User guide: https://imagodata.github.io/filter_mate/guide.html
    💡 Sixteen use cases in English and French: https://imagodata.github.io/filter_mate/stories.html

changelog=v5.0.3 (2026-11-09): Interactive segmentation of a raster (experimental) - a Segment target of the PIPETTE group draws an object from a click or a box with a SAM 2.1 model, locally on the CPU, and the validated polygons filter the other layers without the model. Best on buildings and well delimited objects. FilterMate ships neither the model nor its runtime: onnxruntime is installed by you, the model (62 MB) is downloaded when you ask for it. The object detector is unchanged.
    v5.0.2 (2026-11-06): Changing between vector layers - the single selection list is no longer empty (the link filter of the previous layer stayed on it), no feature appears selected that nobody picked, and the display field chosen for a layer is kept. A vector layer picked before its registration is shown once registered. The dock no longer stops reacting after a layer is removed. Small scaled screens - a 1080p laptop scaled to 150 percent gets the compact profile instead of a dock too tall for its area, and the EXPLORING tools scroll instead of overlapping. The UI_PROFILE setting now works, at once and at startup. Several features that failed only in QGIS work: custom expressions in the exploring features, layers saved without their linking option, choosing where to save a single exported layer, the expression debounce setting. A custom expression matching nothing no longer empties the single selection list. Scrolling the dock no longer changes a list or a number by accident: they answer the wheel once clicked. Search bar in the Configuration tab. One order for the EXPLORING tools on every layer kind.
