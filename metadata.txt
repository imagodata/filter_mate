about=🧭 FilterMate explores, filters and exports vector, raster and LiDAR point cloud layers from one panel.

    Pick a layer, select what matters on it, and FilterMate filters the other layers of the project by their relation to that selection: buildings within 50 m of a road, parcels on a gentle slope, LiDAR points under the buildings, a DTM clipped to a commune. Filters stay on the project layers (no copies), can be undone, saved as favorites, exported and replayed from Processing.

    🧭 EXPLORING selects on the current layer, whatever its kind:
    - 🗺️ vector: one feature, several, or an expression;
    - 🏔️ raster: band, pixel value picked on the map, value range on a live histogram, classes, raster calculator expression;
    - ☁️ point cloud (LAS, LAZ, COPC, EPT, VPC): ASPRS / LiDAR HD classes, Z, intensity and return ranges, attribute conditions, height above a DTM.

    🔍 FILTERING relates that selection to layers of any kind (9 source / target combinations) with geometric predicates, a buffer, AND / OR with existing filters and a minimum coverage. Filtered rasters and point clouds keep their id, style and place in the layer tree, and the project is always saved with the original sources.

    📦 EXPORTING writes the filtered layers: vector formats, GeoPackage with an embedded QGIS project, GeoTIFF / COG, LAZ / LAS / COPC.

    ✨ Also: PostgreSQL / PostGIS, Spatialite, GeoPackage and OGR backends with spatial indexes; undo / redo; favorites shared through git repositories; Processing algorithms and models, qgis_process, Python and REST APIs; light and dark themes; 34 languages. QGIS 3.22 to 4.x, Qt5 and Qt6.

    🔧 Optional: psycopg2 for PostgreSQL, PDAL 2.4+ for the height above a DTM and COPC writing.

    📖 User guide: https://imagodata.github.io/filter_mate/guide.html

tracker=https://github.com/imagodata/filter_mate/issues

changelog=v5.0.0 (2026-10-20): FilterMate 5 - raster and LiDAR point cloud layers are sources and targets like vector layers. EXPLORING adapts to the current layer: raster band, pixel picker, value range with histogram and live preview, classes of paletted rasters, raster expression; point cloud ASPRS / LiDAR HD classes, Z / intensity / return ranges, chained attribute conditions, height above a DTM (PDAL), tiles of the same dataset. FILTERING keeps its form and relates that selection to vector, raster and point cloud targets (9 combinations, buffer, minimum coverage, Disjoint); clipped rasters (VRT) and point clouds (COPC) keep the layer id and style, follow undo / redo, are restored on unload and never written to the project file. EXPORTING writes GeoTIFF / COG and LAZ / LAS / COPC / GPKG / CSV. Raster pipette (similar pixels, clicked object, every similar object), BANDS block with colour roles and spectral presets, raster read tile by tile at the native resolution; point cloud value pipette and zone shapes; similar features and synced selection modes on the vector rail; selection strip and per-target centroids. Web services (WFS, OGC API Features, ArcGIS, WMS / WMTS / XYZ, WCS, vector tiles, remote COPC / EPT) are filtered with bounded, cancellable reads and no network read on the main thread. Automation: 9 Processing algorithms, 4 models, qgis_process, Python, REST and MCP APIs. Raster and point cloud support on by default, switched live in Configuration. Fixes found by the new CI runs on QGIS 3.22 to 4.2 (engine and dock): QGIS crash when the panel opened on QGIS 3.22-3.34, possible crash when a layer was removed, plugin not loading before QGIS 3.34.2, rasters not clipped with GDAL older than 3.9, point clouds with PDAL older than 2.4, modal extension dialog at every start, FILTERING rows thousands of pixels apart. Breaking: Favorites Sharing refuses a plaintext auth_header, use the QGIS Authentication Manager (authcfg_id).
