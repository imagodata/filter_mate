开源 QGIS 插件

从一个位置，筛选整个 QGIS 工程。

选择单个要素、多个要素或 QGIS 表达式。FilterMate 会将空间规则一次应用于所有目标图层，支持 GeoPackage、PostGIS、SpatiaLite 其他矢量数据源、栅格与 LiDAR 点云，无需编写 SQL。

操作流程

一次选择，覆盖所有相关图层。

FilterMate 将常见的多图层 GIS 操作整理为三个清晰步骤。应用前可先检查选择内容和设置。

  1. 01

    选择数据源

    选择单个要素、勾选多个要素、使用地图选择结果，或输入 QGIS 表达式。

  2. 02

    设置空间规则

    选择目标图层、空间关系及可选的缓冲区。应用筛选前先确认源要素。

  3. 03

    使用结果

    在地图上检查数量、撤销或保存筛选条件，再按需导出筛选后的图层。

FilterMate 5 新功能

栅格与 LiDAR 点云，像任何图层一样筛选。

将栅格或点云设为当前图层，EXPLORING 就会显示相应的工具；FILTERING 再把选择结果与任何类型的图层关联起来。

  • 栅格波段、像素拾取、带直方图与实时预览的数值范围、由 DTM 计算的坡度、坡向、山体阴影或粗糙度、类别、栅格表达式。
  • 点云ASPRS 与 LiDAR HD 类别、任一属性的条件、类别结合高于 DTM 的高度。
  • 任意方向矢量、栅格与点云都能作为源或目标：九种组合，并支持缓冲区、最小覆盖率与 Disjoint。
  • 可放心撤销裁切后的图层保留原有 ID 与样式。撤销、重做和工程文件都会回到原始数据源。
  • 导出栅格输出 GeoTIFF 与 COG；点云输出 LAZ、LAS、COPC、GPKG 与 CSV。
  • 网络服务WFS、OGC API Features、ArcGIS、WCS、矢量切片，以及远程 COPC 或 EPT 点云，都以有上限的读取方式筛选和浏览，且绝不在主线程上进行。
  • 自动化十个 Processing 算法、四个模型、qgis_process，以及 Python 与 REST API。
  • 已验证每次发布前都在 QGIS 3.22 至 4.x 中验证，涵盖 Processing 和面板本身。

实验性 · FilterMate 5.1 新功能

用一句话提出筛选需求。

AGENT 是面板顶部的聊天区。写下你想要的内容，例如所选市镇中海拔 1200 m 以上的建筑，它就会筛选、选择、缩放或导出。每一步都可以撤销。

阅读 Agent 章节 → (EN)
  • 你的模型Claude、Mistral、OpenAI 或兼容服务器使用你自己的 API 密钥，密钥保存在 QGIS 认证数据库中；本地的 Ollama 模型则不需要密钥。设置界面会引导这两种方式。
  • 逐步撤销筛选会立即应用。Undo 和 Redo 会逐个走过代理的请求，Undo back to here 则可回到任意一步。
  • QGIS 算法它能搜索并运行会产生图层或统计值的 Processing 算法，输入为工程中的图层。每个结果都是临时图层，Undo 会将它移除。
  • 由你确认导出，以及添加或移除图层，都会先询问。筛选条件只是一条单纯的 WHERE 子句，执行前会先检查。
  • 由你勾选的来源开放数据门户、WFS 服务、Sentinel-2 影像和 MCP 连接器，在你勾选之前全部关闭。
  • 先取得你的同意在你选好模型并同意之前，不会发送任何内容。指南列出了每次请求会一并发送的内容。
  • MCP 服务器默认关闭。你电脑上的 Claude Code 或其他 MCP 客户端，可通过 127.0.0.1 并凭访问令牌操作 FilterMate。

实验性 · FilterMate 5.1 新功能

点一个对象，SAM 把它画出来。

在栅格上，像素拾取工具会用 SAM 画出点选的对象；SAM 是在你电脑上运行的模型。相似对象会以建议的形式出现，由你保留或拒绝。结果只是单纯的多边形，所以筛选不需要模型就能重新执行。

日常 QGIS 工作

从数据探索到成果交付。

FilterMate 将从选择到导出的完整流程整合于同一个面板。

  • 探索搜索、在地图上选择、跟踪并缩放至参考要素。
  • 筛选使用八种空间关系、固定距离或表达式缓冲区，以及属性筛选。
  • 恢复撤销或重做筛选状态，即使重新打开 QGIS 工程后也可操作。
  • 复用将完整配置保存为收藏，并与团队共享。
  • 导出将筛选后的图层、样式和内嵌工程写入 GeoPackage，或使用其他 QGIS 格式。
  • 自动化通过 Processing、模型或 Python，将同一表达式应用于多个图层。
