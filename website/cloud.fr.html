Nos engagements

Cinq règles que nous tenons

Elles valent quoi qu’il arrive à l’offre payante.

  1. Aucune fonction du plugin n’est jamais verrouillée ni limitée dans le temps.
  2. Tout ce qui est payant tourne sur un serveur et apporte ce que votre ordinateur seul ne peut pas faire.
  3. Le compte est facultatif : votre propre clé et Ollama continuent de fonctionner sans lui.
  4. Rien ne part vers un serveur sans que vous l’ayez activé ; ce qui est envoyé est consigné par écrit.
  5. Les rappels de l’offre payante sont rares et placés là où ils aident.
