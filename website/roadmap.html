Beyond Vectors:
Raster & LiDAR Filtering

EXPLORING selects on the current layer, whatever its kind. FILTERING relates that selection to vector, raster and point cloud layers with its usual predicates and buffer.

Released on 2026-10-15. FilterMate 5.0 filters vector, raster and point cloud layers. Raster and point cloud support is on by default and can be switched off in the Configuration tab. Every release is tested in CI on QGIS 3.22, 3.28, 3.34, 3.44 and 4.2, with Processing and with the dock itself.

How it works

EXPLORING selects, FILTERING relates

The selection on the source becomes a source geometry; each target kind applies the geometric predicates in its own way.

Unchanged
Vector source
Features picked in EXPLORING (single, multiple, expression), as today. Vector targets keep the existing engine; raster and point cloud targets are clipped by the same buffered geometry.
SelectionFeatures
Raster source
A value range on a histogram, the classes of a paletted raster or a raster calculator expression. The kept pixels are vectorized and become the source geometry.
SelectionPixels
Point cloud source
ASPRS / LiDAR HD classes, Z, intensity and return ranges, height above a DTM. The footprint of the kept points becomes the source geometry.
SelectionPoints
Vector targets
Features that satisfy the predicates, with an optional minimum coverage for polygons (for example, parcels at least 50 % inside an elevation range).
TargetSubset
Raster targets
Pixels outside the source geometry become NoData through a clipped virtual file; Disjoint keeps the outside. The layer keeps its id, style and place in the legend.
TargetClipped VRT
Point cloud targets
Points outside the source geometry are removed through a derived COPC file written with PDAL (or the QGIS exporter); Disjoint keeps the outside.
TargetDerived COPC
Raster

An EXPLORING panel for rasters

Band, pixel picker, value range, classes and raster expression, with a live preview on the map.

Key feature
Pixel picker
Click on the map to read the value of every band; Ctrl+click extends the selected range to that value.
EXPLORING
Value range and histogram
Drag the two handles of the histogram or type the bounds; the share of selected pixels updates as you go, and a preview hides the other pixels.
EXPLORING
Classes and expressions
Paletted rasters (land cover) select by classes; any raster can use a raster calculator expression, also across several rasters.
EXPLORING
Export
A filtered raster is written as GeoTIFF or Cloud Optimized GeoTIFF, pixels outside the filter set to NoData.
EXPORTINGGeoTIFF / COG
LiDAR & Point Cloud

An EXPLORING panel for point clouds

LAS, LAZ, COPC, EPT and virtual point clouds; the criteria stack and the panel input is kept per layer.

Key feature
Classes with presets
ASPRS classes plus the LiDAR HD ones (permanent above-ground structures, virtual points…), with presets: ground, vegetation, buildings, above ground, water, without noise.
EXPLORING
Attribute ranges
Z with three decimals, intensity, first / last / single return, and an editable expression for anything else.
EXPLORING
Height above a DTM
Pick a terrain model: PDAL adds a HeightAboveGround dimension, then "vegetation higher than 2 m" is a live filter.
EXPLORINGPDAL
Tiles and export
Apply a selection to every tile of a LiDAR HD dataset; export filtered points to LAZ, COPC, GeoPackage or CSV.
EXPORTINGLAZ / COPC

What 5.0 delivers

Times measured on one IGN LiDAR HD tile (1 km², 25.1 million points) with a 1 m DTM and BD TOPO buildings, QGIS 4.2.

Released
Panels, cross filters, export
Raster and point cloud panels, the nine source → target pairs, undo / redo, favorites, project save and reopen, export of every kind, nine Processing algorithms, four models, the Python and REST APIs.
2
Measured
From a fraction of a second to a few seconds
Raster clipped by buildings: 0.5 s. Point cloud clipped by five buildings: 0.7 s. Parcels by elevation range: 0.2 s. Point cloud clipped by an elevation zone: 14 s (4 million points rewritten).

Tested
QGIS 3.22 to 4.2
A CI job loads FilterMate in the official QGIS Docker images (3.22, 3.28, 3.34, 3.44, 4.2) and drives the dock under Xvfb. Point clouds need QGIS 3.26 or later; PDAL 2.4 or later is optional (height above a DTM, direct COPC writing).

What's new

Since the 5.0.0 release

Merged on the main branch between 2026-10-16 and 2026-10-18, on its way to the next release on plugins.qgis.org. Details in the changelog.

Pipette
Three targets for the raster pipette
Similar pixels of the whole raster (a colour on an orthophoto, a value, a class), the clicked object only (the connected patch: a pool, a roof, a field, outlined on the map) or every object of the raster like the clicked one, within chosen area ratios. Ctrl+click adds a pick; the selection strip gives the kept share.
EXPLORINGRaster
Bands, every-band mode, spectral presets
A BANDS block with the colour role of each band (R, G, B, NIR; RGB, IRC and RGB + NIR shortcuts), a value range applied to every colour band at once, and NDVI / NDWI / ExG presets in the raster expression.
EXPLORINGRaster
Raster source at the native resolution
The selected pixels are read tile by tile at full resolution in a background task, within a budget of 200,000 vertices: a 125 m² pool on 25 cm pixels stays exact where the previous 4-megapixel grid lost half of it.
FILTERINGRaster
Point cloud rail: value pipette and zone
A click writes a condition around the picked value of the chosen attribute; a rectangle, polygon, freehand shape or circle cuts the footprint of the source. Emptied targets are named as such, the COPC clip runs twice as fast, a geographic source is read at the right resolution.
EXPLORINGLiDAR
Similar features and synced selection modes
On a vector layer, one click selects every feature with the clicked one's value of the group expression. The rail tools and the selection groups of the three kinds follow the same five rules: a tool is available with its group, switching it on activates the group, both come back with the layer.
EXPLORINGVector
Selection strip, hybrid targets, centroids per target
One band between EXPLORING and FILTERING says what the source hands over (features, raster range and pixel share, LiDAR classes and points). Each target says what the filter does to it; each line or polygon target has its own centroid toggle.
FILTERING
MCP server for AI assistants
A Model Context Protocol server over stdio, started outside QGIS, with one tool per REST endpoint: list layers, apply or cross filter, geometry and point cloud filters, favorites, export. The API key comes from the environment; remote URLs are refused unless allowed.
AutomationREST
Fixes
Rasters and point clouds missing from the targets when a QGIS 3 config.json was redirected; a colour selection with no preview; point cloud exports reading a copy of the layer (36 s instead of 153 s); the last Qt6 enums; the plugin repository security scan clean again.
