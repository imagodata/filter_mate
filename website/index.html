FilterMate

Pick a place, a feature or an expression. FilterMate filters every layer of your QGIS project around it, on PostGIS, GeoPackage, Spatialite or shapefiles, without a line of SQL.

Find the feature first

Type a name, tick a few features in a list, or write an expression. With tracking on, the map follows the selection, so you see what you are about to filter with.

  • Single selection: Toulouse
  • Multiple selection: four neighbours
  • Expression: population above 20,0007 communes

Then filter everything around it

Choose the layers to filter, a spatial predicate and, if you need one, a buffer. Filter rewrites the subset of every target layer at once; Undo brings back the previous state.

A whole department, as it comes

Every video on this page runs on the complete BD TOPO of Haute-Garonne: one 2.9 GB GeoPackage, 1.17 million buildings, nothing clipped beforehand. FilterMate asks each table's R-tree index first, so the twelve layers of a commune filter in under a second. On PostgreSQL the work stays in the database.

Keep what works

Each filter goes into a history of the project that you can undo and redo, even after restarting QGIS. Save a configuration as a favorite, replay it tomorrow, share it with your team.

  • Saved as a favorite: PPRI Garonne 300 m
  • All filters cleared

Take the result with you

Export the filtered layers to one GeoPackage with their styles and a QGIS project inside, or to any format QGIS writes, and zip it for delivery. Open the file and the whole map comes back.

Install FilterMate

FilterMate is on the official QGIS plugin repository. It is free, open source and translated into 34 languages.

  1. Open the plugin managerPlugins › Manage and Install Plugins…
  2. Search for FilterMatein the All tab
  3. Click Installthe FilterMate button appears in the toolbar
