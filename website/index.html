Open-source QGIS plugin

Filter a whole QGIS project from one place.

Choose a feature, a list or a QGIS expression. FilterMate applies the spatial rule to every target layer at once — on GeoPackage, PostGIS, SpatiaLite and other vector sources, without writing SQL.

The workflow

One selection. Every relevant layer.

FilterMate turns a recurring multi-layer GIS operation into three explicit steps. You can inspect the selection and settings before anything changes.

  1. 01

    Choose the source

    Pick one feature, tick several, mirror a map selection or write a QGIS expression.

  2. 02

    Set the spatial rule

    Select the target layers, predicate and optional buffer. Check the source selection before applying the filter.

  3. 03

    Use the result

    Review counts on the map, undo or save the filter, then export the scoped layers when needed.

Daily QGIS work

From exploration to a deliverable.

FilterMate keeps the full workflow in one dock instead of scattering it across temporary layers and one-off queries.

  • ExploreSearch, select on the map, track and zoom to the reference features.
  • FilterUse eight spatial predicates, numeric or expression-based buffers and attribute filters.
  • RecoverUndo and redo filter states, including after reopening the QGIS project.
  • ReuseSave complete configurations as favorites and share them with a team.
  • ExportWrite filtered layers, styles and an embedded project to GeoPackage, or use other QGIS formats.
  • AutomateApply one expression to several layers from Processing, a model or Python.

Install FilterMate in QGIS.

FilterMate is published in the official QGIS plugin repository under GPL-3.0.

  1. Open the plugin managerPlugins › Manage and Install Plugins…
  2. Search for FilterMatein the All tab
  3. Click Install Pluginthen open FilterMate from its toolbar button
