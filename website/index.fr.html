Extension QGIS libre

Filtrez tout un projet QGIS depuis un seul lieu.

Choisissez une entité, une liste ou une expression QGIS. FilterMate applique la règle spatiale à toutes les couches cibles — sur GeoPackage, PostGIS, SpatiaLite et les autres sources vectorielles, sans écrire de SQL.

Le fonctionnement

Une sélection. Toutes les couches utiles.

FilterMate ramène une opération SIG multicouche récurrente à trois étapes explicites. Vous contrôlez la sélection et les réglages avant toute modification.

  1. 01

    Choisir la source

    Prenez une entité, cochez-en plusieurs, reprenez la sélection cartographique ou écrivez une expression QGIS.

  2. 02

    Définir la règle spatiale

    Sélectionnez les couches cibles, le prédicat et, si besoin, le tampon. La source du filtre reste visible.

  3. 03

    Exploiter le résultat

    Contrôlez les comptes sur la carte, annulez ou enregistrez le filtre, puis exportez les couches utiles.

Le travail quotidien dans QGIS

De l’exploration au livrable.

FilterMate garde tout le flux dans un même panneau, sans multiplier les couches temporaires ni les requêtes jetables.

  • ExplorerRechercher, sélectionner sur la carte, suivre et zoomer sur les entités de référence.
  • FiltrerUtiliser huit prédicats spatiaux, des tampons numériques ou par expression et des filtres attributaires.
  • RevenirAnnuler et rétablir les états, y compris après la réouverture du projet QGIS.
  • RéutiliserEnregistrer les configurations complètes comme favoris et les partager en équipe.
  • ExporterÉcrire couches filtrées, styles et projet embarqué dans un GeoPackage, ou utiliser les autres formats QGIS.
  • AutomatiserAppliquer une expression à plusieurs couches depuis Processing, un modèle ou Python.

Mesuré, sans sous-entendu

Les grandes sources peuvent rester grandes.

FilterMate choisit un moteur pour chaque couche vectorielle et exploite les index spatiaux natifs lorsqu’ils existent. Ces chiffres décrivent l’exemple documenté de Haute-Garonne, pas une performance garantie partout.

Libre et gratuit

Installez FilterMate dans QGIS.

FilterMate est publié dans le dépôt officiel des extensions QGIS sous licence GPL-3.0.

  1. Ouvrir le gestionnaire d’extensionsExtensions › Installer/Gérer les extensions…
  2. Chercher FilterMatedans l’onglet Toutes
  3. Cliquer sur Installer l’extensionpuis ouvrir FilterMate depuis son bouton dans la barre d’outils
